# ArkOps 界面与交互迭代记录（UI Loop）

> 与 `iteration-log.md` 的分工：功能/治理变更写 `iteration-log.md`（P 编号）；界面与交互变更写本文（U 编号）。
> 每轮只写：为什么、改了什么（用户可感知）、强化了哪一层、边界与取舍、验证结果。

## 记录格式

```
## U{编号}.{子项} — {一句话标题}（{可读|可行|可信}）

**为什么**：走查证据（页面 / 文件位置 / 行号 / 现象）。
**改了什么**：用户能直接感知到的变化，不写实现细节。
**强化了哪一层**：可读 / 可行 / 可信，一句话说明。
**边界与取舍**：本轮不做什么，为什么。
**验证**：npm run build；scripts/check-hex.sh；亮/暗 + 1440/1024 走查结论。
```
